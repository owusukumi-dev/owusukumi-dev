## Projects

### [3D Rasterizer from Scratch](https://github.com/owusukumi-dev/rasterization-from_scratch-c)

**C · SDL2**

I built a software rasterizer to understand what actually happens between mathematical coordinates and the pixels that appear on a screen.

It grew from manually writing pixels into a framebuffer to 3D transformations, perspective projection, backface culling and basic Lambertian lighting.

---

### [Binary Telemetry Server](https://github.com/owusukumi-dev/lowlatency-telemetry-server)

**C · Java · Winsock · Java NIO**

A cross-language telemetry system I built while learning how information actually moves between programs and computers.

The C server streams binary telemetry over TCP using a small custom protocol, while the Java client handles framing, decoding, reconnection and concurrent processing.

---

### [Market Sentinel](https://github.com/owusukumi-dev/forex-quantitative-backend)

**Python · Node.js · Express · MySQL**

This started because I wanted to understand how trading bots generate signals.

I began with RSI and moving averages, then kept asking where the data and market movements actually came from. That eventually led me into macroeconomic data, web scraping, backtesting and building a pipeline connecting Python analysis to a Node.js dashboard.

---

### [Pharmacy Guard](https://github.com/owusukumi-dev/pharmacy-inventory-backend)

**Node.js · Express · MySQL · JavaScript**

An unfinished pharmacy POS and inventory system that started as an attempt to build software I could sell to real pharmacies.

It includes JWT authentication, role-based access, sales and inventory tracking, and a stock-audit system for comparing recorded inventory with physical counts.

The project taught me a lot about designing software around real users rather than just making the code work.
